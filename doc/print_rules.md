# 打印文本规则说明

本文档梳理 btprint-sdk 的文本打印规则，重点说明**文本太长时的换行处理行为**。
规则来源：`BtPrintManager`（组包）+ 打印机固件（自动换行）。

## 1. 编码与字符宽度

- 所有文本以 **GBK** 编码发送（`CHARSET_GBK`）。
- 字符宽度计算规则：**ASCII 字符宽 1，其余字符宽 2**（按码点 `> 127` 判断）。
  - 英文/数字/半角符号：宽 1，GBK 占 1 字节
  - 汉字/全角符号：宽 2，GBK 占 2 字节
  - 扩展拉丁字符（如 `é`）：GBK 中也是 2 字节，宽 2，一致
- 编码替换坑：emoji、生僻字等 **GBK 无法表示的字符会被替换为 `?`**（1 字节），
  但宽度计算按原码点（可能算 2）——多列排版中这类字符可能造成 ±1 列的偏差。

## 2. 纸张与行宽

SDK 内置两种纸宽（`BtPrintManager.PaperWidth`，可用 `setPaperWidth` 切换并持久化）：

| 纸张 | 每行字符数（标准字号） | 每行打印点数 | 适用 |
|---|---|---|---|
| MM_58（默认） | 32 | 384 | 58mm 小票机 |
| MM_80 | 48 | 576 | 80mm 小票机 |

"每行字符数"指标准字号（Font A 12×24 点）下满行能容纳的宽度单位：英文 32/48 个，
或中文 16/24 个，或混合按宽度累计。**该值只参与 SDK 侧的排版计算**
（printTwo / printThree / printDivider / printImage），printText 的行宽完全由打印机决定。

## 3. printText：换行规则（核心）

```
printText(text, fontSize, align, feedLines)
```

**SDK 不做任何拆行处理**：整段文本转成 GBK 字节流，连同对齐、字号命令和
`feedLines` 个换行符一次性写入。文本超长时的换行完全由打印机固件完成。

### 3.1 打印机自动换行行为

- 打印机按打印头位置**逐字符累计宽度**，到达右边界时自动回车走纸换行；
- 换行以**整个字符**为单位，GBK 双字节字符不会被拆到两行；
- **不会断英文单词**——按字符流依次排列，词中间到边界就直接断开换行；
- 换行后**对齐方式、字号保持不变**（ESC/POS 这些是状态型命令，持续生效直到被改写）。

### 3.2 手动换行与空行

- 文本中嵌入 `\n`：GBK 编码后就是 `0x0A`（LF），强制换行——这是控制长文本版面的唯一手段；
- `feedLines`（默认 1）：文本末尾追加 N 个空行；传 0 则不额外走纸；
- 常用技巧：空文本 + `feedLines = n` 即打 n 个空行（`PrintUtils.printEmptyLines` 的实现）。

### 3.3 字号对行宽的影响

printText 发送的字号命令与实际行宽的关系：

| fontSize | 发送的命令 | 58mm 实际行宽 | 80mm 实际行宽 | SDK 排版按 |
|---|---|---|---|---|
| SMALL | `ESC ! 0x01` + `ESC M 0`（Font B，9×17 点） | 约 42 列 | 约 64 列 | 32 / 48（保守） |
| NORMAL | `ESC ! 0x00` + `ESC M 0`（Font A，12×24 点） | 32 列 | 48 列 | 32 / 48（精确） |
| LARGE | `ESC ! 0x33` + `ESC M 0`（倍宽倍高） | 约 16 列 | 约 24 列 | 32/48 ÷ 2 |

要点：

- **SMALL 字号下行宽变大**，一行能塞更多字符；SDK 多列排版仍按标准行宽计算，属保守估计，
  不会错位，只是列间距比理论最大窄；
- **LARGE 字号行宽减半**，超长文本会自动折成两倍行数，折行后对齐方式保持；
- 个别机型对 `ESC ! 0x33` 的放大倍数解释不同（×2 / ×4），若发现大字体多列排版超宽，
  属机型差异，可换 `setFont` 或调整文本规避。

### 3.4 超长文本示例

58mm 机器、NORMAL 字号、左对齐，打印 40 个汉字（宽 80，超出 32）：

```
SDK 发送：  [ESC a 0][ESC ! 0][ESC M 0] + 80 字节 GBK + [0A]
打印机输出：第 1 行 16 个汉字（32 宽度单位，到边界自动换行）
            第 2 行 16 个汉字
            第 3 行 8 个汉字 + 走纸 1 行（feedLines=1）
```

## 4. printTwo：两列排版的超宽规则

```
printTwo(text1, text2, fontSize)
```

1. 按第 2 节规则算出行宽 `totalWidth`（LARGE 字号减半）；
2. 计算 `w1 = 宽(text1)`、`w2 = 宽(text2)`：
   - **放得下**（`w1 + w2 ≤ totalWidth`）：单行输出，中间补 `totalWidth - w1 - w2` 个空格；
   - **放不下**：**不截断**，自动改为两行——`text1` 一行，`text2` 下一行（均左对齐）。

例（58mm、NORMAL）：`printTwo("商品名称特别长的商品", "100.00")`，
w1 = 20 > 32 - 6，输出两行而非截断。

## 5. printThree：三列排版的超宽规则

```
printThree(text1, text2, text3, fontSize)
```

1. 行宽换算同 printTwo；`rem = totalWidth - w1 - w2 - w3`；
2. **`rem < 0`（总宽超行）**：`text1` 独占一行，剩余空间按 `w2 + w3` 重新计算，
   `text2`、`text3` 排在第二行——中右列不会在单行里硬塞；
3. 未超宽时：按"左列是否短于半行"分两种空格分配策略，把 `text2` 尽量推到行中、
   `text3` 推到行尾；
4. 全部输出左对齐（显式发送 `ESC a 0`，不继承外部对齐状态）。

## 6. 分割线与标题

```
printDivider(char, length)   // 默认 "-"，length=-1 时铺满当前纸宽
printTitle(text, ...)        // 分割线 + 大字体居中文本 + 分割线
```

- 分割线是 `char × N` + 换行，**强制居中**，结束后恢复左对齐；
- `char` 为宽字符（如 `＝`）时按宽 2 折算个数，保证铺满整行；
- `length > 0` 时按指定字符数输出，可打出短分割线。

## 7. 打印后的状态残留

各方法执行完毕后打印机的状态（影响后续任务的呈现）：

| 方法 | 对齐 | 字号 |
|---|---|---|
| printText | 保持本次设置的 align | 保持本次设置的 fontSize |
| printTwo / printThree | 恢复左对齐 | 保持本次设置的 fontSize |
| printDivider | 恢复左对齐 | 不变 |
| printQrCode / printBarCode / printImage | 恢复左对齐 | 不变（码图尺寸与字号无关） |
| cutPaper / openCashDrawer | 不变 | 不变 |

即：**对齐是每次排版方法自管的，跨任务不会错位；字号是持续状态**，
大字号打印后记得用下一次 printText 的 fontSize 或 `setFont` 调整。

## 8. 常见坑速查

| 现象 | 原因 | 对策 |
|---|---|---|
| 长文本折行位置不符合预期 | 换行由打印机固件按点宽决定 | 文本内自行插入 `\n` 控版 |
| 英文单词被从中间折断 | 自动换行不断词 | 自行断词 + `\n` |
| 中文变成 `?` | GBK 无此字符（emoji/生僻字） | 文本过滤或改用图片打印 |
| 大字体排版超宽 | 机型对放大倍数解释不同 | 缩短文本或降字号 |
| 两列对不齐 | 文本含 GBK 不可编码字符 | 过滤非常规字符 |
| 打完标题后正文也变大 | 字号是持续状态 | 后续 printText 显式传 fontSize |
